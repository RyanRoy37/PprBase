# Complete sample papers

These documents were generated by PprBase from complete dummy question sets. Each paper has an editable Word file, a printable PDF, and a separate answer key:

| Marks | Subject | Questions | Word paper | PDF paper | Answer key |
|---:|---|---:|---|---|---|
| 25 | Biology | 12 | `25_mark_biology.docx` | `25_mark_biology.pdf` | `25_mark_biology_answers.docx` |
| 50 | Chemistry | 24 | `50_mark_chemistry.docx` | `50_mark_chemistry.pdf` | `50_mark_chemistry_answers.docx` |
| 100 | Science | 48 | `100_mark_science.docx` | `100_mark_science.pdf` | `100_mark_science_answers.docx` |

The tests check every question, the marks total, section numbering, answer keys, images, tables, saved draft recovery, DOCX archive integrity, and A4 PDF rendering. Results are in `test_report.json`.

To regenerate the documents:

```bash
./venv/bin/python -m scripts.generate_sample_papers
```

These papers contain made-up classroom content for testing. Review questions and answers before using any of them with students.
